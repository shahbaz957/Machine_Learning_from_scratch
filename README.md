# Machine Learning from Scratch  

This repository contains implementations of fundamental **statistical, optimization, and machine learning algorithms** built completely **from scratch** (without using high-level ML libraries).  
It is designed for students, researchers, and practitioners who want to understand the **mathematical foundations and working principles** of conventional machine learning algorithms — the basis of modern Artificial Intelligence.  

---

## Features  

- Implementations of classical ML algorithms from scratch in **Python (Jupyter Notebooks)**.  
- Covers **Regression, Classification, Clustering, Optimization, and Ensemble Methods**.  
- Includes both **theoretical explanations** and **step-by-step code**.   

---

## 📂 Repository Structure  

Each `.ipynb` notebook demonstrates one algorithm or ML Technique:  

### 🔹 Regression  
- Linear Regression (with Gradient Descent)  
- Logistic Regression (using Gradient Descent)  
- Ridge Regression  
- Lasso Regression  
- Elastic Net Regression  
- Key Assumptions of Linear Regression  

### 🔹 Classification & Nearest Neighbours  
- K-Nearest Neighbour (KNN)  

### 🔹 Clustering  
- K-Means Clustering (from scratch + standard version)  
- Agglomerative Hierarchical Clustering  
- Clustering on World Countries (case study)  

### 🔹 Ensemble & Boosting Methods  
- Bagging Ensemble Learning  
- AdaBoost (with Hyperparameter Tuning)  
- Gradient Boosting Algorithm  
- Feature Importance in Random Forest  

### 🔹 Optimization  
- Batch Gradient Descent  
- Stochastic / Mini-batch Gradient Descent (where applicable)  

### 🔹 Special Topics  
- Handling Imbalanced Dataset  

### 🔹 AND MUCH MORE
